# Автоматическое создание досок YouGile

1. Создайте **приватный** репозиторий GitHub и загрузите в корень `create_week.py` и папку `.github/workflows/weekly.yml`.
2. В Settings → Secrets and variables → Actions → Secrets создайте `YOUGILE_API_KEY` и вставьте ключ YouGile.
3. Если в компании есть несколько проектов с одинаковым названием, добавьте в Variables `YOUGILE_PROJECT_ID` — точный UUID проекта, полученный через API `GET https://yougile.com/api-v2/projects`. Иначе скрипт найдёт проект по точному названию «Текущая работа элеватора».
4. В Actions включите workflow, если GitHub предложит это сделать.
5. Проверьте автоматический запуск в ближайшую субботу. Кнопка Run workflow создаёт доску сразу, поэтому для проверки без создания доски используйте отдельный тестовый проект.

Запуск: суббота 06:00 Europe/Moscow. Создаётся доска на следующую рабочую неделю, 6 колонок, без задач. Повторные запуски дополняют недостающие колонки, не создавая дубли. GitHub может запускать расписание с задержкой. Не публикуйте API-ключ в коде.
